How to Get Yahoo Finance Data into Excel: 3 Methods

2026-10-19

Getting Yahoo Finance data into Excel

You want stock prices or financial data in an Excel workbook. This guide covers one job: getting the data from Yahoo Finance into Excel. Three methods work. They differ in effort, in how reliable they are, and in how often you can refresh the data.

For CSV formats in general, read the CSV export guide. For formulas and analysis once the data is in, read the Excel stock analysis guide.

Method 1: Download a CSV and open it in Excel

The simplest route needs no extra tools. Yahoo Finance has offered a CSV download on the Historical Data tab of many stock pages. If your page shows the option, use it.

  1. Open the stock's quote page on finance.yahoo.com and go to the Historical Data tab.
  2. Set the date range you need.
  3. Use the download link to save the file as CSV.
  4. In Excel, import the file with Data → From Text/CSV instead of double-clicking it. Check that the Date column is a date and the price columns are numbers, then load the table.

Limitations

  • One ticker at a time
  • Historical prices only, no financial statements or dividend records
  • The download option is not on every page
  • Refreshing means repeating the download by hand

Method 2: Power Query web import (no file)

Excel's Power Query can read a table straight from a web page, so you skip the file. Menu names vary a little between Excel versions. Yahoo Finance pages are built with scripts, so the result depends on what the page delivers when Excel loads it.

  1. Copy the address of the Historical Data page for your ticker.
  2. In Excel, go to Data → Get Data → From Web and paste the address.
  3. In the Navigator window, select the table that holds the prices. If no table appears, this method will not work for that page.
  4. Click Transform Data to check the column types (dates and numbers), then choose Close & Load.
  5. To update later, use Data → Refresh All.

Limitations

  • Often shows no table, or a cookie or consent page, instead of the data
  • Breaks when Yahoo Finance changes its layout, sometimes without an error
  • After every refresh, check the first and last date and the row count

Method 3: FinGrab extension (one export, clean file)

FinGrab is a Chrome extension that adds an export button to Yahoo Finance quote pages. It reads the ticker from the page, fetches the data from Yahoo Finance, and processes it in your browser. You still open the file in Excel, but the file is already clean: one row per period and named columns, so there are no import settings to fix.

  1. Install FinGrab from the Chrome Web Store.
  2. Open the stock's quote page on finance.yahoo.com.
  3. Click the FinGrab button on the page. The ticker is already filled in.
  4. Choose a time period and an interval: daily, weekly, or monthly.
  5. Download the CSV and open it in Excel.

The file contains date, open, high, low, close, adjusted close, and volume. The adjusted close accounts for splits and dividends, so long price charts stay consistent.

Limitations

  • Chrome only
  • Each export is one click, so it is quick for a few tickers and repetitive for dozens

Common problems when importing into Excel

  • Numbers show up as text: import with Data → From Text/CSV and set the price columns to Decimal Number.
  • Dates are wrong or day and month are swapped: set the Date column type explicitly in the import dialog. The regional setting of your Excel decides how dates are read.
  • Prices differ from the Yahoo chart: compare the Close and Adj Close columns. Adjusted close also accounts for dividends, so the two differ on dates with payouts.

Get started

For a one-off export, Method 1 costs nothing. If you update the same workbook regularly, the fastest path is FinGrab: install it and export your next dataset in under two minutes. Prefer a walkthrough with screenshots? See the two-click guide to stock prices in Excel.
